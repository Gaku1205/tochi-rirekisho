# tochi-rirekisho

福岡市の住所を入れると、古い地形図と公開データでその土地の昔と災害リスクをAIが読み解く履歴書にするサービス

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（面接で語れる、AIとデータを工夫して使った本格的なWebサービス）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
