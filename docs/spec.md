# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

福岡市の住所を入れると、古い地形図と公開データでその土地の昔と災害リスクをAIが読み解く履歴書にするサービス（元のメモ：面接で語れる、AIとデータを工夫して使った本格的なWebサービス）

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 福岡市で部屋や家を探している人が、候補の住所を入れて「昔は田んぼか池か、浸水や地盤はどうか」を内見の前に確かめる
  - 地元の歴史が好きな人が、自分の住む町の1926年・1948年・1975年といまを、境目をずらして見比べる
  - 調べた結果を縦長の1枚の画像にして、家族や部屋探しの相手にスマホで送る
  - 登録なしで誰でも使う。調べられるのは福岡市の7区だけ
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
