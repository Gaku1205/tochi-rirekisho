# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## このサービスらしさ
- 考え：この画面では、古い地形図が、その土地の名前を映画の題名のように読ませる景色（画面いっぱいの背景と、昔と今をずらす境目）になる。
- しるし（どの画面にも必ず出す物）：①本物の古い地形図か空中写真を、色を変えずに大きく ②町名を Shippori Mincho B1 で大きく、不透明の砂色の札に載せる ③年号は Bodoni Moda
- 埋める物：大きい文字は町名（トップは画面の高さの約1/4、結果は 96px）と年号。色の面は砂色の地・墨のAIの要約と年代の帯・苔の選んだ年代と押す所。本物の素材は五万分の一地形図「FUKUOKA」と地理院タイル（空中写真 1948・1975・いま）、大橋駅の写真。中身は12の町の記録
- 新しい画面・部品を足すとき：まず「この画面の地図はどれか」を決める（古い地形図・空中写真・いまの地図のどれかを、画面の半分以上に）。文字は地図の上なら砂色の札、紙の上なら砂色の地に墨。使ってよい構図は、全面の地図＋札／左の紙＋右の地図（分割）／不揃いの帯／地図の上の1枚の紙。使わない物：白い角丸のカード、細い罫線、影、半透明・ぼかし、見出しの上の小さいラベル、番号の札、等幅の数字、描いた地図
- 浸水・地盤の危なさは、ほかの記録と同じ行の並びで淡々と出す（赤や警告の色を使わない）

## 参考にした実例
- Layers of London（https://www.layersoflondon.org/）：古い地図を画面いっぱいの景色にして、文字は不透明の色の面に載せる
- YCAM（https://www.ycam.jp/）：全面の絵の左下に不透明の札。札の中の文字の大きさの差
- 星のや（https://hoshinoya.com/）：文は1行だけ、あとは場所の絵に任せる
- ArcGIS StoryMaps（https://storymaps.arcgis.com/）：地図を画面の高さに固定し、文だけがスクロールする
- 撮った画像は `factory-refs/shots/`、考え方は `factory-refs/board.md`

## 文字
| 役 | 書体 | 大きさ・行間 |
| --- | --- | --- |
| 町名・欄の名前 | Shippori Mincho B1 800、字間 -0.02em | トップ clamp(120px, 21vh, 220px)（スマホ 104px）／結果 96px（中くらい・スマホ 64px）／欄の名前 34〜56px。行間 0.95〜1.1 |
| 年号・大きい数字 | Bodoni Moda 500、lining・tabular | 年代の帯 40px（スマホ 24px）／履歴書の行の年号 108px（中くらい 80px・スマホ 76px）／浸水・地価の数字 96px（中くらい 80px・スマホ 68px）／似た土地の数字 40px／調べられる町の数 220px（スマホ 140px） |
| 本文 | Jost（欧文・数字）＋Murecho（和文）400・500・700 | 本文 16〜18px・行間 1.6〜1.8／要約 19px・500／注 15px |

- 4つの書体はオーナーが選んだ組み合わせ（`inspect.mjs` の font-count はこの理由で残す）
- 明朝は地名と欄の名前だけ。字間を広げない
- 画面の文言は日本語。見出しは何の欄かが分かる名詞

## グリッドと余白
- 外の余白 32px（760px 以下は 16px）
- 結果の画面：左の紙 560px＋右の地図（1100px 以下は 400px＋地図）。右は画面の高さに固定（sticky）。760px 以下は、地図（58svh）→年代の帯→紙の順に縦に
- 区切りは線ではなく、面の濃さの差（砂→沈んだ砂→墨）と余白（欄の間 80〜120px）
- 角はすべて直角

## 部品
- 札：砂色の不透明の面。地図の上の文字は必ず札に載せる（地図は薄めない）
- 境目の地図：左に選んだ年代、右にいまの地図。境目は墨の 6px の線と 56px の四角いつまみ（キーボードの左右で動く）。最初は左から62%。拡大縮小は＋−（48px）・ホイール・ピンチ・ダブルクリック。地点は深い緑の丸（砂色の縁）。似た土地は墨の札（町名と数字）で、枠の端に掛かる札は出さない
- 選んだ地点の印と札（結果の画面の地図）：印は地点の印と同じ深い緑の丸（22px、砂色の 4px の縁）。札は砂色の不透明の面（幅 252px、余白 14px 16px、中の間 12px、角なし・影なし）で、印の 20px 上に中央を合わせて出す（枠の上に近いときは印の下）。横は枠から 12px 内に収める。町が見つかったときは、町名を Shippori 800 の 28px（墨）、下に苔のボタン「この地点の履歴書を見る」（幅いっぱい、52px）。範囲の外は墨の 16px・500 で「ここは調べられる町から遠すぎます」だけ。ボタンやリンクは出さない
- 地図の下の注（`.side-note`）：「地図を押すと、その地点を調べられます（スマホは長押し）」。薄墨・15px・行間 1.5、余白 10px 16px 12px。地図と年代の帯のすぐ下
- 年代の帯：墨の地に4つのボタン（年号＋短い言葉）。選んだ物は苔色（aria-pressed）
- 履歴書の年代の行：箱にしない。左にその年の地図・空中写真を同じ地点で切った正方形（132px、中くらい 96px・スマホ 88px。真ん中に緑の点）、右に年号（行の主役）・太字の様子・説明。大橋2丁目は「2026」の行の下に、楠の写真を左の欄の幅いっぱい（4:3）で、左下に墨の札の説明
- 浸水・地盤・地価：箱にしない。上に墨の 6px の帯を1本、項目名（17px・700）、値を大きく（浸水・地価は Bodoni の数字、地盤は Shippori 44px の言葉）、説明
- 浸水が「データなし」の町：大きな数字の代わりに、薄墨 `--soft` の Shippori 34px の言葉「データなし」を出す（下の説明は通常の本文）。赤・警告の色・アイコンは使わない。シェア画像では値の文字を薄墨にする
- トップでは左の欄の頭のナビを出さない（上の札のナビと2つにしない）。住所欄から始める
- AIの要約：墨の面に砂色の文字、下に「AIが読み解いた要約」の注
- 似た土地：沈んだ砂の行に、町名・共通点・数字（Bodoni）・言葉（深い緑）
- ボタン：苔の面、白い文字、高さ 52px、角なし。2つ目は墨
- 住所欄：沈んだ砂の面、高さ 52px、右に「調べる」

## 動き
- しるしの動き：地図のシャッター（上から開く 1.1s、中の地図は 1.08 倍から落ち着く）。1画面に1か所
- 札：0.35s 遅れて下から浮かぶ（0.6s）
- 選んだ地点の札：動かさず、すぐ出す・すぐ消す（アニメーションなし）
- 欄の部品：行は左から、紙は下から、絵は下から開く（`data-reveal="row|rise|wipe|fade"`、`src/components/Reveal.tsx`）
- 調べている間：墨の全面に町名、年号4つが順に灯る
- `prefers-reduced-motion` ではすべて止める

## 絵の扱い
- 古い地形図：五万分の一「FUKUOKA」（AMS L772 Sheet 4147-I、1945年刷り）。図郭の内側だけを切り出した `public/photos/fukuoka-1926.jpg`。図郭の旧日本測地系の経緯度を世界測地系に直して重ねる（`src/lib/layers.ts`）
- 空中写真・いまの地図：地理院タイル（std・ort_USA10・gazo1・seamlessphoto）。大橋のまわりのズーム14〜16は `public/tiles/`、外は地理院から読む
- 色を変えない・ぼかさない・半透明を重ねない
- 出どころは画面の下の注と、このサービスについての「データの出どころ」に必ず書く
